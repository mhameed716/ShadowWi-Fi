# ShadowWi-Fi

مشروع Android Studio بلغة Kotlin وJetpack Compose Material 3 لفحص بوابة Captive Portal على الشبكة الحالية وتجربة رمز واحد يُدخله المستخدم يدوياً.

## الوظائف

- تبويبان عبر Bottom Navigation: **البوابة** و**التشخيص**.
- فحص `http://connectivitycheck.gstatic.com/generate_204` مع التقاط تحويلات 301/302/307/308 ومحاولة قراءة رابط/عنوان صفحة البوابة.
- عنوان MikroTik الافتراضي عند تعذّر الاكتشاف: `http://192.168.88.1/login`.
- محاولة POST يدوية واحدة عند ضغط المستخدم، بالحقول `username` و`password` و`dst`، ثم التحقق من استجابة الإنترنت واستخراج رسالة بوابة مقروءة عند توفرها.
- اختبار اتصال الإنترنت ونسخ تقرير تشخيصي لا يتضمن رمز الدخول.
- OkHttp وKotlin Coroutines، مع تنفيذ طلبات الشبكة خارج واجهة المستخدم.

## نطاق الاستخدام الآمن

هذا الإصدار لا يتضمن تخميناً آلياً، أو محاولات جماعية من ملف، أو مولّد قوائم كلمات مرور/أكواد. الشاشة الثانية مخصّصة لتشخيص الاتصال بدلاً من توليد قوائم تخمين. لا تُرسل إلا رمزاً تملك صلاحية استخدامه، وعلى شبكة تملكها أو لديك إذن بإدارتها.

## فتح المشروع

1. فك ضغط مجلد المشروع إن كنت تستخدم ملف ZIP.
2. افتح مجلد `ShadowWiFi` في Android Studio حديث يدعم Android Gradle Plugin 8.7.3 وKotlin 2.0.21.
3. دع Gradle يزامن الاعتماديات، ثم شغّل تطبيق `app` على جهاز Android 8.0 (API 26) أو أحدث. للبناء من الطرفية استخدم `./gradlew assembleDebug` (في Windows: `gradlew.bat assembleDebug`).

يتطلب البناء Android SDK 35 وJDK 17. ملف Manifest يطلب `INTERNET` و`ACCESS_NETWORK_STATE` فقط، ويسمح بـ HTTP الصريح لأن بعض بوابات الشبكات المحلية تستخدمه. لا يطلب التطبيق صلاحيات تخزين أو موقع.

## الحزم الأساسية

- Jetpack Compose + Material 3
- OkHttp 4.12.0
- Kotlin Coroutines 1.9.0
