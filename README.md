# ShadowWi-Fi — أدوات بوابة الشبكة

تطبيق أندرويد مبني بـ **Flutter** يتيح فحص بوابة الشبكة (Captive Portal) المتصلة بها، وتشخيص تفاصيل الاتصال، وتسجيل محاولات الدخول، وعرض شبكات الواي فاي القريبة.

الواجهة بالكامل **داكنة** وبالعربية، مع أربعة أقسام في شريط التنقل السفلي.

## 2. الأقسام الأربعة (شريط التنقل السفلي)

### ① البوابة

- **اكتشاف البوابة الافتراضية**: يقرأ البوابة من إعدادات النظام عبر قناة المنصّة الأصلية، وعند تعذّر ذلك يجرّب العناوين الشائعة (192.168.1.1، 192.168.88.1، 10.0.0.1 …) ثم يرجع للقيمة الافتراضية.
- **واجهة إدخال يدوية نظيفة**: اسم المستخدم أو رقم الجهاز، كلمة المرور/الرمز، ووجهة الاتصال، مع زر «تسجيل الدخول» ولوحة نتيجة تعرض رمز HTTP وعنوان الصفحة.
- **اختيار ملف TXT** من ذاكرة الجهاز عبر `file_picker` (سطر واحد لكل رمز، والأسطر التي تبدأ بـ `#` تُعتبر تعليقات).
- **تشغيل تلقائي** يقرأ الملف ويجرب الرموز تباعاً داخل **Isolate منفصل** فلا تتجمّد الواجهة أبداً.
- **زر إيقاف مؤقت / استئناف / إلغاء** لإيقاف الحلقة في أي لحظة.

### ② التشخيص

يعرض: نوع الاتصال، حالة الإنترنت (فحص `generate_204` مع زمن الاستجابة ورمز HTTP)، عناوين IP للجهاز، البوابة الافتراضية، خوادم DNS، عنوان صفحة البوابة ورمز استجابتها — مع SnackBar داكنة عند أي خطأ.

### ③ السجل

يسجّل كل محاولة (يدوية أو تلقائية) مع الوقت والنتيجة ورمز HTTP والمدة، ويوفّر:

- زر **مسح السجل** مع نافذة تأكيد.
- زر **تصدير** ينشئ ملف `.txt` محلياً ويشاركه عبر `share_plus`.

> التخزين محلي وغير مشفّر (خارج نطاق هذه النسخة).

### ④ الشبكات

- قائمة **شبكات الواي فاي القريبة** مع الاسم، قوة الإشارة (dBm + مؤشر أعمدة)، النطاق (2.4 / 5 / 6 جيجاهرتز)، ونوع الحماية (WPA3، WPA2، WPA، WEP، مفتوحة) بأيقونة مناسبة لكل حالة.
- **الضغط على أي شبكة آمنة** يفتح نافذة سفلية لإدخال كلمة مرور الشبكة أو الرمز، أو اختيار ملف TXT — ثم تشغيل **حلقة التجربة التلقائية** (داخل Isolate) حيث يُجرَّب كل رمز ككلمة مرور على بوابة الشبكة **بدون اسم مستخدم**، مع أزرار بدء/إيقاف مؤقت/استئناف/إلغاء وشريط تقدم عائم أثناء التصفح.
- **سحب للتحديث** (`RefreshIndicator`) لإعادة الفحص.
- **إدارة إذن الموقع أثناء التشغيل** عبر `permission_handler`: طلب الإذن قبل الفحص تلقائياً، إعادة التحقق عند العودة من إعدادات النظام (مراقب دورة حياة التطبيق)، شرح للمستخدم عند الرفض، وزر لفتح إعدادات التطبيق عند المنع النهائي.

## 3. التحسينات الأربعة المطبّقة

| # | التحسين | مكان التنفيذ |
| --- | --- | --- |
| 1 | تنفيذ الحلقة داخل **Isolate منفصل** (بدون تجميد الواجهة) | `lib/data/services/auto_fill_runner.dart` |
| 2 | **إيقاف مؤقت / استئناف / إلغاء** للحلقة | `AutoFillRunner` + `lib/state/portal_controller.dart` |
| 3 | **إدارة أذونات الموقع ديناميكياً** أثناء التشغيل | `lib/data/services/permission_service.dart` + `lib/state/networks_controller.dart` |
| 4 | **سحب للتحديث** لإعادة فحص الشبكات | `lib/ui/features/networks/networks_screen.dart` |

**خارج النطاق**: التخزين المحلي المشفّر لسجل المحاولات (السجل يُحفظ بصيغة JSON عادية).

## 6. التشغيل والبناء

```bash
# 1) تثبيت الحزم
flutter pub get

# 2) تشغيل على جهاز أو محاكي متصل
flutter run

# 3) بناء حزمة التثبيت
flutter build apk --release

# 4) تشغيل الاختبارات
flutter test

# 5) تحديث الأيقونات بعد تغيير assets/icon/icon_source.png
python3 tool/generate_icons.py
```

> إن فتحت المشروع من Android Studio اختار مجلد `android/`، وإلا سيتولى `flutter run` إعداد `local.properties` وواجهة Gradle تلقائياً.

## 7. الأذونات المطلوبة

| الإذن | السبب |
| --- | --- |
| `INTERNET` | الاتصال بالبوابة والتحقق من الإنترنت |
| `ACCESS_NETWORK_STATE` | قراءة حالة الاتصال ونوع الشبكة |
| `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` | قراءة شبكات الواي فاي القريبة |
| `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION` | إظهار أسماء الشبكات ونتائج الفحص على أندرويد 9+ |

## 8. قناة النظام الأصلية

`MainActivity.kt` يوفّر القناة `com.shadowwifi.app/system` بالطرق التالية:

| الطريقة | النتيجة |
| --- | --- |
| `getGateway` | البوابة الافتراضية من DHCP |
| `getDnsServers` | خوادم DNS الحالية |
| `getDeviceInfo` | عناوين IP، اسم الواجهة، وعنوان MAC |
| `getWifiInfo` | SSID وBSSID وقوة الإشارة والتردد |

## 9. استخدام مسؤول

هذا التطبيق مخصص لفحص واختبار **البوابات التي تملكها أو تديرها** (شبكة منزلية، فندق، حرم جامعي، أو بيئة اختبار). استخدمه فقط على شبكات تملك صلاحية إدارتها، ولا تستخدمه على شبكات لا تملك إذناً بها. الرموز المستخدمة في الملفات يجب أن تكون رموزاً تملك حق استخدامها.
